# Инструкция: заказ печатных плат power_board в Резоните

Нужно заказать только изготовление плат, без пайки деталей (без монтажа).

## Что понадобится

- Архив **gerber/power_board_gerber.zip**: в нём все слои платы и файлы сверловки.
- Паспортные данные плательщика, если заказ от физического лица.
- Контактные телефон и e-mail.

## Параметры платы

| Параметр | Значение |
|---|---|
| Тип | Многослойная, **типовая сборка** |
| Количество слоёв | 4 |
| Размер | 56,5 × 45 мм (одна плата) |
| Материал | FR4 Tg150 (типовой) |
| Толщина | 1,6 мм |
| Фольга | 35 мкм |
| Финишное покрытие | Самое дешёвое из предложенных. Иммерсионное золото тоже подходит: дороже, но площадки ровнее |
| Маска | Зелёная |
| Маркировка | Белая |
| Исполнение | Одиночные платы, не панель |
| Количество | 5 шт. |
| Монтаж, трафарет | Не нужны |

Обязательно выберите «типовую сборку». Для нетиповой минимальный заказ 4 дм², это заметно дороже.

Плата проходит по базовым нормам Резонита: зазор и проводник от 0,2 мм, отверстия от 0,3 мм ([нормы Резонита](https://www.rezonit.ru/pcb/mnogosloynye-platy-tipovye-sborki/)).

## Порядок слоёв

После загрузки архива проверьте, что слои распознались так:

| Слой | Файл |
|---|---|
| Top (верхний) | power_board-F_Cu.gtl |
| Внутренний 1 | power_board-In1_Cu.g1 |
| Внутренний 2 | power_board-In2_Cu.g2 |
| Bottom (нижний) | power_board-B_Cu.gbl |
| Контур | power_board-Edge_Cuts.gm1 |
| Сверловка | power_board-PTH.drl (NPTH.drl пустой, это нормально) |

## Как оформить заказ

1. Зайти в личный кабинет [my.rezonit.ru](https://www.rezonit.ru/account/) и зарегистрироваться.
2. Создать Клиента: физическое лицо или организацию.
3. Нажать «Создать проект», выбрать категорию «Многослойные платы, типовая сборка».
4. Загрузить gerber/power_board_gerber.zip.
5. Проверить порядок слоёв по таблице выше.
6. Выставить параметры из таблицы «Параметры платы». Если какое-то значение распознано автоматически неверно, переключить с «авто» на «свои».
7. Проверить сводку параметров и нажать «Сохранить проект», затем «В корзину».
8. В корзине выбрать количество (5 шт.) и срок.
9. Указать плательщика, доставку и контакты, отправить заказ.

Другой способ: отправить архив и заполненный бланк заказа на pcb@rezonit.ru. Бланк лежит на странице [«Как сделать заказ»](https://www.rezonit.ru/order/).

## Ориентировочная стоимость

Площадь одной платы 0,255 дм², пяти плат около 1,27 дм².

| Вариант | Расчёт | Примерно |
|---|---|---|
| Стандартный срок | 3600 ₽ подготовка + 1,27 дм² × 930 ₽ | ~4,8 тыс. ₽ |
| Срочно (от 6 рабочих дней) | ×2 | ~9,6 тыс. ₽ |
| Суперсрочно (от 4 рабочих дней) | ×3 | ~14,4 тыс. ₽ |

Цены из [прайса Резонита](https://www.rezonit.ru/price_pcb/) на 4-слойные платы, действуют с 03.08.2026. Стандартный срок сейчас считают по запросу. Точную сумму покажет калькулятор в личном кабинете.

## Если завод задаёт вопросы

- **Проект разведён в KiCad 10.** Если попросят исходники, приложите power_board.kicad_pcb.
- **«Под микросхемами U1 и U2 много мелких отверстий».** Это теплоотводящие переходные отверстия 0,3 мм, так и задумано.
- **Предупреждения о шелкографии** (надписи налезают на площадки). Разрешите обрезать надписи по маске.
- Любые другие вопросы перешлите разработчику платы.
